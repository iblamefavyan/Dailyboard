# DailyBoard

DailyBoard adalah aplikasi dashboard untuk mengatur tugas dan catatan.

Fitur
- Menambah tugas
- Menghapus tugas
- Mengedit tugas dengan double click
- Menandai tugas selesai
- Filter tugas
- Pencarian tugas
- Menambah catatan
- Mengedit catatan dengan double click
- Menghapus catatan
- Dark Mode
- Kutipan harian
- Informasi cuaca
- LocalStorage
- Responsive untuk mobile dan desktop


- HTML
- CSS
- JavaScript
- LocalStorage
- Fetch API

Cara Menggunakan

1. Tambahkan tugas pada bagian Tugas.
2. Klik tugas untuk menandainya selesai.
3. Double click tugas untuk mengedit.
4. Tambahkan catatan pada bagian Catatan.
5. Double click catatan untuk mengedit.
6. Gunakan Dark Mode untuk mengganti tema.
7. Masukkan nama kota untuk melihat cuaca.

Struktur File
- index.html
- style.css
- main.js
- tugas.js
- catatan.js
- storage.js
- api.js
